# Sports Card Grading ROI Lab

Interactive client-side calculator for raw vs PSA 9 vs PSA 10 sports-card grading economics.

## Features
- Scenario sale, net, profit and ROI calculations
- Expected-value modeling using user-defined grade probabilities
- Raw and graded break-even calculations
- Responsive market-terminal style interface

## Data integrity
This is a modeling calculator, not a verified market-price feed. Enter assumptions from completed sales or another trusted market-data source.
